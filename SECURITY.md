# Security Policy

## Responsible Use & Ethics Statement

A.R.E.S. (Autonomous Reconnaissance & Exploitation System) is developed strictly for:
- Authorized penetration testing and security auditing
- Educational learning and ethical hacking labs (e.g. HackTheBox, TryHackMe, VulnHub)
- Defensive security assessment and vulnerability remediation

**Prohibited Use:**
Using A.R.E.S. against systems without prior, explicit, written authorization from the system owner is illegal and strictly prohibited. The project maintainers accept no liability for damages or misuse resulting from this software.

## Reporting a Vulnerability in A.R.E.S.

If you discover a security vulnerability within A.R.E.S. CLI itself (e.g. unintended command injection, privilege escalation bug):
- **Do not open a public GitHub issue.**
- Please send an advisory through [GitHub Private Vulnerability Reporting](https://github.com/Antim8er/ARES/security/advisories) or contact the maintainers directly.
- Include detailed steps to reproduce the issue and an assessment of its impact.
