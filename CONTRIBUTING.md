# Contributing to A.R.E.S. CLI 🧠

Thank you for your interest in improving A.R.E.S.! We welcome contributions from penetration testers, security researchers, and developers.

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Antim8er/ARES.git
   cd ARES
   ```

2. **Create a virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: .\venv\Scripts\activate
   ```

3. **Install dependencies in editable mode:**
   ```bash
   pip install -e .
   pip install pytest
   ```

4. **Run the test suite:**
   ```bash
   pytest
   ```

## Development Guidelines

- **Safety First:** Commands generated by ARES must never bypass user confirmation flags without explicit opt-in (`--auto-confirm`).
- **Sanitization:** All shell executions must go through platform-appropriate sanitization or elevation wrappers.
- **Code Style:** Keep code clean, type-annotated, and compatible with Python 3.8+.
- **Pull Requests:** Provide a clear description of the problem solved, and ensure all tests pass before submitting.
